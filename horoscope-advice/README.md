# Leo × Scorpio Daily Advice

A lightweight web app that delivers horoscope-inspired guidance tailored to a Leo born on **August 4** and a Scorpio born on **November 17**. The advice refreshes automatically each midnight based on the current weekday and surfaces:

- **Shared Focus** — one theme for the couple to align on
- **Individual Spotlight** — Leo & Scorpio specific nudges
- **Micro Challenge** — a playful action to try together
- **Tonight's Debrief** — one question to close out the day intentionally

## Getting Started

```bash
npm install
npm run dev  # serves at http://localhost:4173
```

## Tooling

- **Vanilla HTML/CSS/JS** for zero-build hosting (ideal for GitHub Pages)
- **htmlhint** to lint the markup (`npm run lint`)
- **serve** to preview locally (`npm run dev`)

## Deploying

The site works anywhere static assets can be hosted. Point your host (GitHub Pages, Netlify, Cloudflare Pages, etc.) at the project root so `index.html` is served from `/`.
